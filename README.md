# WorkBuddy Desktop Pet

面向 **Windows 11 / Windows 10 x64** 的 WorkBuddy 专用桌面宠物。

让桌面角色跟随 WorkBuddy 的工作状态变化，在任务完成或需要你确认时提醒你，并支持点击唤起 WorkBuddy。

[下载 Windows 最新版](https://github.com/zhujiaowo-sudo/workbuddy-desktop-pet/releases/latest) · [自制素材与模板](docs/materials.md) · [项目上下文](docs/project-context.md)

## 已实现功能

- 状态动画：空闲、思考、执行工具、等待输入、等待审批、完成、失败。
- 多会话状态汇总：优先展示需要用户处理的会话，避免子任务完成导致整项任务被误报完成。
- 提醒：等待确认提示、任务完成通知、点击后确认已读。
- 桌面交互：左键人物轮换招手/比心/害羞/惊讶，闲置随机吃零食/玩手机/伸懒腰/听音乐，右键选择模块；拖动、位置记忆和系统托盘。
- 每日签到：左侧圆钮查询WorkBuddy签到状态，独立授权后点击领取；已签到不重复提交，超时不自动重试领取。
- 接入诊断：区分未连接、已收到事件与连接过期，不把没有数据显示为空闲。
- 数据面板：只读本地积分记录，按请求元数据关联模型，支持全部/7天/30天；未知模型、缺时间明确列出。
- 集成卡片：胶囊点击进入紧凑数据模式，再展开详情、数据看板、素材或设置；闲置可自动缩成胶囊。
- 数据模式：显示会话名称与任务状态、个人账户剩余积分、本机今日消耗；今日按本地零点计算，不受看板日期范围影响。
- 会话跳转：点击会话名称直达对应 WorkBuddy 对话，兼容当前 Windows 协议注册。
- 仅卡片模式：隐藏人物并释放动画，保留状态、统计与设置；程序包不包含外部人物动画。
- 自制素材：ZIP/文件夹导入、预览、启用、删除、模板导出；PNG/APNG、GIF、WebP；新版完整包需15段动画，旧包仍可只有待机。默认轻量/高清示例包独立下载，详见[素材制作说明](docs/materials.md)。
- 聊天跳转：小卡聊天图标、右键“在 WorkBuddy 中聊天”和 `--chat` 均直接打开当前 WorkBuddy 对话；无当前会话时打开主窗口。桌宠不再提供聊天输入框、模型连接设置或模型调用。

审批继续在 WorkBuddy 内完成。本机积分统计不代表完整账户账单；上下文 used/size 不累计为 Token 消耗，Auto 缺少实际响应模型时明确标记未知。聊天内容由用户在 WorkBuddy 中发送。

## 启动与连接

下载 Windows 程序包，完整解压后运行 `WorkBuddyDesktopPet/WorkBuddyDesktopPet.exe`。首次自动检测运行进程、协议/安装注册表及常用目录；在连接引导点击“同意并完成绑定”，安装本地状态插件并按勾选授权余额/签到。未授权不会读取本地连接票据。请先在 WorkBuddy 登录，再新建任务验证状态插件；旧会话未加载时保存工作后重新打开 WorkBuddy。设置中的“检测”可重新定位，也可手动选择程序。

左侧圆形快捷按钮可在设置中选为签到、WorkBuddy 官网、自定义网页或刷新数据。网页仅允许 HTTP(S)，仅点击时打开。手动收成胶囊会连同人物一起隐藏，点击胶囊展开恢复；右键人物菜单包含“退出桌宠”。剩余积分按整数向下取整显示，右侧框根据数字长度自适应宽度。

人物隐藏后，胶囊按自身高度独立拖动，可以贴到任务栏上方的可用区域底部；右键胶囊选择“显示桌宠”即可恢复。贴底恢复时整组自动上移，保持胶囊在人正上方8px；隐藏状态及胶囊位置会保存。仅卡片模式不会因普通展开被取消，显式选择“显示桌宠（退出仅卡片模式）”才恢复人物。“重置位置”返回主屏右下角并保留模式。

薄荷1.4.0待机约3秒眨眼一次，闲置18–40秒偶尔挠头，共用同一基础身体，腿部不拼接、脸型固定，手臂按固定部件旋转；不再把两幅人物图混合成中间帧。右键只保留一个人物开关，按人物可见性显示“收成胶囊”或“显示桌宠”；小卡“−”只缩小卡片，可保留“人物+胶囊”。既有45–110秒休闲、任务/审批/点击优先级不变。旧素材与静态形象不强制替换，新动作需更新默认动画。

软件启动后及每6小时后台检查正式版本；发现新版显示版本及更新内容，确认后下载、校验并安装重启。进度、取消、失败重试、稍后安装及失败回退见[软件更新](docs/updating.md)。旧版首次需手动安装本版。

点击会话胶囊进入320×202的数据小卡；右键人物也可选择小卡、详情、数据、聊天、素材或设置。蓝色顶栏提供刷新、详情、统计、聊天跳转、设置和收起；聊天直接打开 WorkBuddy，展开面板仅保留详情、数据、素材、设置。小卡及完整看板都居中放在人物可见轮廓上方；空间不足时整组让位、详细内容区缩短并可滚动。

胶囊为签到圆钮、会话、粗体积分三段，外围透明。拖动胶囊模块可移动整组。左键人物轮换4种反应并弹出约3.2秒短句；取消整个人物弹跳与叠帧，按真实素材帧播放；执行任务显示坐姿电脑，屏幕朝人物。连续闲置45–110秒后随机播放零食/手机/伸懒腰/音乐6–10秒，新任务立即打断休闲，确认/等待/失败提示优先。不改变真实任务状态、提醒或积分。旧素材与静态形象由内置道具补充。

只用卡片可运行随包的 `仅卡片启动.vbs`，或在“设置”勾选“仅显示卡片”。素材页提供导入、模板导出和可选动画下载；不下载动画也可使用薄荷星伴静态形象。

默认形象“薄荷星伴”由Buddy娘提供，采用[CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/)；来源和内置首帧导出说明见[NOTICE](NOTICE.md)。旧机器人创作模板保持独立CC0许可。

胶囊按人物可见轮廓上方8个逻辑像素停靠，忽略窗口和素材画布的透明留白。动画以整段帧轮廓并集定位，播放时不会逐帧跳动；放大人物不再同步放大中间空白。

任务栏、托盘、窗口及程序文件图标固定为原始蓝色小搭子，不提供修改入口；导入、切换或删除人物素材均不会改变应用图标。

胶囊旁只显示剩余积分数字，提示中可查看含义和更新时间。在设置中启用“授权本地查询剩余积分”后，通过WorkBuddy本地WBIPC转发读取真实个人积分摘要，每60秒刷新，任务结束后会提前更新。连接票据只用于本机握手，不上传、不写入桌宠日志；登录凭据由WorkBuddy自身持有。查询失败时显示“积分待同步”，不以本机消耗推算余额。点击徽标进入数据模式并刷新；顶栏刷新同时更新余额与本机统计。今日消耗不含缺时间或未来的请求，仅代表可读取的本机记录。

每日签到另有“授权查询签到，点击按钮时领取”开关，默认关闭，余额授权不会自动启用签到。启用后每5分钟及跨日只查询状态；**仅点击左侧签到圆钮会先查询、再领取**。已签不重复领取；网络超时只刷新状态，不重试领取。成功后从WorkBuddy重新查询余额，不在本机自行加分。服务要求额外验证时，请在WorkBuddy中处理。签到接口依据WorkBuddy5.9.2本机静态源码接入，真实状态查询及领取实测范围见兼容性记录。

审批继续在 WorkBuddy 内进行；桌宠只负责提醒。首次安装默认不启用登录自启，可在设置中开启。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.lock
.venv\Scripts\python launch.py --demo
.venv\Scripts\python launch.py
```

源码运行需要 Python 3.12。可执行程序包无需自行安装 Python。构建与移除说明见 [Windows 使用文档](docs/releasing.md)。

## 技术

- Python 3.12+：状态转换、事件读取、设置与诊断。
- PySide6 Essentials：Windows 透明窗、角色绘制、系统托盘和通知。
- WorkBuddy Hook 插件：采集最少的结构化生命周期事件。
- PyInstaller：打包 Windows x64 程序。
- pytest：验证事件处理、多会话状态、断连和配置维护。

## 接入边界

WorkBuddy 官方文档列有 Hook 插件，但具体事件与负载需要在目标桌面版实测。CodeBuddy CLI 文档中的事件不能直接视为 WorkBuddy 桌面版已支持的能力。

目前已观察到 `SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop` 和 `Notification`。此版本中的通知事件尚未提供已识别的通知分类，不能据此宣称等待审批或等待输入已在本机验证。

使用 `--demo` 的界面明确显示“演示”，其事件不写入真实队列。未观察到的事件不当作已验证能力。

Hook 适配器仅记录事件类型、时间、会话标识及必要的工具分类。不收集对话内容、提示词、工具参数、文件正文、登录凭据或 API 密钥。
