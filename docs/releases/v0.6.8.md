# v0.6.8 · 当前用户一体安装向导

新增中文EXE安装包：默认安装到当前用户程序目录，无需管理员权限；首次在同一向导选择 WorkBuddy 接入、积分查询、手动签到和可选登录自启，完成后可启动桌宠。WorkBuddy 登录和任务审批仍需由用户完成。

已有用户更新保留角色、外部素材、模式和授权；已有接入自动迁移到安装位置。未检测到 WorkBuddy 或接入失败会提示从设置重试，不显示虚假的连接成功。Windows 应用列表支持卸载，移除本安装拥有的接入和自启，保留用户数据。ZIP更新保留卸载器，便携包继续提供。

本版包含 v0.6.7 的本机统计字段兼容与分类错误提示。两套内置角色及全部原始动画不变。

下载 `windows-x64-setup.exe` 按向导安装；便携用户可继续选择 `windows-x64.zip`。附件校验值见 `SHA256SUMS.txt`。安装包未做代码签名。

验证范围包括授权选择、旧授权保留、失败分支、卸载所有权、更新卸载文件保留，以及隔离目录中的真实安装、升级和卸载。真实 WorkBuddy 连接范围继续以兼容性记录为准。

本地188项回归及冻结程序检查通过；真实安装器隔离演练通过。Windows CI结果见本版本对应提交的Actions记录。
