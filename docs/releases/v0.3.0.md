# v0.3.0 · 胶囊、数据小卡与展开看板

- 点击人物或会话胶囊先进入紧凑数据模式：显示会话名称、任务状态、个人账户剩余积分及本机今日消耗。
- 采用蓝色快捷顶栏：刷新、详情、统计、聊天、设置、右上角收起。素材入口在小卡右下方，右键人物也可直达各页。
- 点击统计等入口，详情区在小卡上方展开；关闭展开区返回数据模式。小卡320×202，避免常驻大面板。
- 胶囊仅保留会话和积分两个模块，去掉外围白底与蓝边；余额只显示数字，不带“余”。仍居中停靠人物正上方，拖动胶囊模块可移动整组。
- 今日按系统本地零点至当前时刻计算，不受看板全部/7天/30天筛选影响；缺时间、未来和重复元数据不重复计入今日。
- 新任务元数据尚未同步时显示“当前会话”，避免把旧会话名称错误配到新任务上。

剩余积分沿用已授权的WorkBuddy本地只读查询。今日消耗只涵盖可读取的本机记录，不代表完整账单。统计不读取聊天正文；登录及审批仍由WorkBuddy处理。

程序包不含外部人物动画，内置原创矢量角色可直接使用。现有设置、素材与余额授权保留；可选轻量/高清素材及开放制作模板仍通过v0.2.0附件下载。

验证：67项自动化测试通过；合成数据验证三级导航、透明胶囊、日期边界、数字余额、拖动、页面布局、1.5倍DPI和旧功能回归。冻结程序已通过三种视图启动、Hook输入转发、素材导入和仅卡片验证；本机已更新至v0.3.0，连接与真实余额查询正常。
