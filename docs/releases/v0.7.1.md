# WorkBuddy Desktop Pet v0.7.1

恢复可选的常驻窗口，新增三套配色、透明胶囊和更醒目的积分数字。

- **窗口模式**：选择“桌宠＋窗口”或“仅窗口”，即可常驻查看任务、剩余积分、今日消耗与近7天本机积分趋势。右上角仅两个按钮：切回胶囊、打开看板。关闭看板或按Esc返回窗口；切回胶囊保留人物显隐。
- **配色与透明底**：右键“外观”和设置页提供灰白、白蓝、红白。胶囊透明底为独立开关，保留文字对比度、点击与拖动区域；窗口和完整看板保持实底。选择在重启后保留。
- **加粗积分**：胶囊、圆形积分徽标、小窗口与看板采用粗体数字，长数值按可用空间调整字号。
- **实际本机趋势**：复用现有只读统计，不增加授权；缺少时间或读取失败明确显示，不伪造账户周额度、Token或重置倒计时。窗口常驻时继续播放正常随机待机。

下载 `workbuddy-desktop-pet-0.7.1-windows-x64-setup.exe`，按当前用户向导安装或升级。ZIP便携包和SHA256校验文件同时提供。保留角色选择、导入素材、已有授权和回退目录；三个内置角色的原始GIF未改动。

验证包含203项自动回归、100%／150%原生界面、冻结程序与Windows安装、升级、卸载检查。截图与测试使用合成数据，不代表所有WorkBuddy版本的真实事件联动。
