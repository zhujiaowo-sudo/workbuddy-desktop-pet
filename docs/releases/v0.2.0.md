# v0.2.0 · 集成卡片与开放素材包

卡片现在集成详情、数据、聊天、素材和设置，人物动画可独立启用或移除。新用户无需下载动画即可使用内置原创“小搭子”，也可通过仅卡片启动入口使用全部卡片功能。

- 本地统计：读取WorkBuddy本机积分记录，按请求关联模型，支持全部/7天/30天；缺模型或时间明确标记。上下文占用不累计为Token，统计不代表完整账户账单。
- 胶囊：闲置可自动收起，点击展开；工作、有未读提醒、输入或操作过程中不会自动收起。可手动保持胶囊。
- 会话：点击名称使用当前WorkBuddy支持的深链进入对话，并恢复最小化窗口。WorkBuddy5.9.2已有真实跳转验证。
- 素材：PNG/GIF/WebP播放器，ZIP/文件夹导入、预览、启用、删除与模板导出。至少一段待机动作即可，其他状态自动回退。下载校验SHA-256；包内无脚本执行能力。
- 默认动画：轻量256px约1.7MB，高清512px约3.4MB，均为本项目原创角色、7种状态，独立于程序包分发。原创导出图像以CC0-1.0提供。
- 独立闲聊：集成Chat Completions模型接口配置，本机HTTP或远程HTTPS；Windows DPAPI保存密钥。聊天不执行工具。

**聊天接入限制：** 随WorkBuddy安装的CLI已尝试文本调用，但本机未获得可用授权回复；不能自动复用WorkBuddy桌面登录或在卡片中控制已有任务对话。使用独立闲聊需配置可用模型接口；也可复制草稿并打开WorkBuddy。接口收发已用本机合成HTTP服务验证，没有使用私有模型密钥做实际模型调用。

**安装：** 完整解压Windows程序ZIP，运行WorkBuddyDesktopPet.exe；只用卡片可运行同目录“仅卡片启动.vbs”。原用户设置和Hook接入继续使用。可选素材包和创作模板无需解压即可在素材页导入。制作规范见materials.md及公开JSON Schema。

**验证：** 49项测试通过；打包版Hook输入、PowerShell转发、GUI启动、素材解码导入、下载清单携带及仅卡片模式验证通过。兼容性记录区分真实事件、合成输入与未验证能力。
