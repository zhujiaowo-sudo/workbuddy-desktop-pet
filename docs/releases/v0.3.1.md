# v0.3.1 · 薄荷星伴默认形象

默认桌宠更换为**薄荷星伴**，作者**Buddy娘**，素材版本1.0.1，许可[CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/)。

- 核心内置透明待机首帧，新安装离线即可显示新形象。
- 默认轻量256px和高清512px动画独立下载，每套包含待机、思考、执行、等待回复、等待确认、完成、失败7状态。
- 两份素材ZIP保持作者原始字节及清单；附带大小和SHA-256校验。
- 保留仅卡片模式、动画导入/删除、现有设置及蓝色三级卡片布局。
- 原CC0机器人保留为资源缺失时的回退和创作模板，新默认素材不适用CC0声明。

附件：

- `workbuddy-desktop-pet-0.3.1-windows-x64.zip`：核心程序，完整解压后运行。
- `mint-orbit-light-v1.0.1.zip`：轻量7状态动画。
- `mint-orbit-hd-v1.0.1.zip`：高清7状态动画。
- `SHA256SUMS.txt`：上述文件的校验值。

素材页点击下载、预览，再点击“启用所选角色”。已有程序也可直接导入本页ZIP使用。来源和内置首帧格式导出说明见[NOTICE](https://github.com/zhujiaowo-sudo/workbuddy-desktop-pet/blob/main/NOTICE.md)。

验证：75项测试通过；冻结程序已验证默认资源、状态插件输入、素材导入、仅卡片及三种视图。本机高清动画已启用，连接与余额查询正常；两套原始素材均经7状态完整解码检查。
