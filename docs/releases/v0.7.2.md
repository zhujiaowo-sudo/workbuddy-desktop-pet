# WorkBuddy Desktop Pet v0.7.2

龙女的拎起与放下更换为用户提供的两段专用动作。

- **拖动拎起、松开放下**：短按继续播放招手等互动；开始拖动时播放拎起，结束后保持悬空，松开播放放下再恢复最新任务／待机。
- **提前松开与再次拖动**：按当前源帧选择对应姿势衔接，等待新段解码期间保留当前帧，避免闪现默认人物；不叠加旧的整图缩放和摆动。
- **原素材保留**：龙女素材更新为1.0.1、20个动作标识。新增两段720×720透明GIF各30帧，时长2040／2020ms，保留原始字节与时序。角色页可预览并导出完整套装。
- **兼容现有使用方式**：其他角色的通用拖动、三色主题、透明胶囊、常驻窗口和授权不变。隐藏、切角色或重要任务提示会取消旧拖拽状态。两个新动作不进入随机待机池。
