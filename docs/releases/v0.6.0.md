# v0.6.0 · 首次绑定、坐姿休闲与自动更新

- 首次启动自动定位 WorkBuddy，集中展示本地状态插件及余额/签到授权，一次确认完成绑定；已有授权保留，设置可重新检测。
- 右键/小卡手动收成胶囊同时隐藏人物，点击胶囊展开恢复；右键新增退出桌宠。
- 左侧圆钮可选签到、WorkBuddy 官网、自定义 HTTP(S) 网页、刷新数据。签到仍只在点击时领取。
- 剩余积分向下取整，取消小数，胶囊右框按位数自适应收窄。
- 薄荷互动素材 1.2.0：坐在椅子上玩手机/吃零食；手机屏幕朝角色，手拿零食送入口边；身体、椅子和脚底固定。保持 Buddy娘/CC-BY-4.0 署名，源图与提示词公开。
- 启动及每 6 小时后台检查正式版本，显示版本与更新说明。确认后下载、显示进度、最多 3 次重试，完整校验后自动安装重启，也可只下载稍后安装。
- 更新助手确认就绪再退出；安装失败回退旧目录。用户设置/素材/自启选择保留，聊天继续直接打开 WorkBuddy。

0.5.1 及更早版本首次需手动安装本版，以后可使用内置更新。程序 ZIP 完整解压，独立人物动画按需下载；CC0 原创机器人模板 2.0.1 保持不变。下载后核对 SHA256SUMS.txt。Windows 安装目录需可写，详见 docs/updating.md。
