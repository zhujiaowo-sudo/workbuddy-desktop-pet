# v0.5.1 · 坐姿平滑动画与聊天跳转

内置聊天受登录和服务端接口限制；按用户要求改为直接在WorkBuddy聊天。删除聊天输入框、模型连接配置及CLI/API聊天后端。小卡聊天图标、右键“在 WorkBuddy 中聊天”和`--chat`统一打开当前会话，没有当前会话则打开主窗口；桌宠不发送模型请求，也不展开聊天面板。

薄荷互动版1.1.1将工作动作换成坐在桌前敲键盘：屏幕朝人物，外侧可见显示器背面。固定桌椅及人物外轮廓，仅更新眨眼和手部局部关键帧。原作者Buddy娘/CC-BY-4.0，新坐姿为内置imagegen生成的派生素材，源图及完整提示词见art/mint-orbit/README.md。

去除点击动画上下弹跳和窗口叠加运动；轻微侧倾、脚底注册、约30fps帧间插值和180ms动作过渡让播放更平顺。隐藏后停止所有播放计时。完整包仍为15段，保留8–16帧、256/512px规范；点击段16帧×160ms，坐姿工作8关键帧×160ms。

附件：Windows核心、薄荷互动1.1.1轻量/高清包、原创CC0机器人2.0.1两档模板和SHA256SUMS。旧发布与原1.0.1素材保持不变。完整解压程序运行，旧用户在素材页下载并启用新版互动包。

验证覆盖聊天跳转/无会话回退、四页面布局、固定桌椅与轮廓、混帧透明度、隐藏播放停止和冻结启动。消息继续在WorkBuddy主程序内由用户发送；余额和签到授权规则保持。
