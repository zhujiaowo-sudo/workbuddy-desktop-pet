# v0.6.1 · 胶囊贴底恢复与灵动待机

- 胶囊右键新增“显示桌宠”，保留全部模块和退出入口；永久仅卡片时明确提示退出该模式。
- 隐藏人物后胶囊独立拖动，可贴到屏幕可用区域底部，不再预留隐藏人物高度。恢复人物时整组自动上移，胶囊继续位于人物正上方。
- 保存独立胶囊坐标和隐藏状态，重启/积分宽度变化保持位置；修复独立卡片“重置位置”不生效，回到主屏右下角并保留显示模式。
- 默认薄荷素材1.3.0新增轻柔眨眼和偶发挠头；身体/脚底固定，无整个人物弹跳。任务、审批、点击、菜单、拖动及原有休闲动作优先，卡片任务文字不改变。
- 素材继续要求15个必填动作，允许可选idle_scratch（8–16帧，40–200ms，非循环）。旧素材继续可用，新扩展包需0.6.1或更新程序；原CC0模板2.0.1保持15动作。
- 完整高清包总解码上限按用户选择提高至7200万像素，可容纳16段各16帧；轻量、旧包和单段保护上限不变。

软件更新保留原角色与用户设置。需要新待机动作请在素材页下载薄荷1.3.0轻量/高清包；不强制下载或替换自制素材。本版继续支持后台检查、一键下载/安装/重启、进度、重试及失败回退。本次位置/素材取舍均已按用户确认实施，冲突检查见docs/plans/2026-10-28-detached-capsule-idle-design.md。
