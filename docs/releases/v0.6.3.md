# v0.6.3 · 长动画播放与视频待机

桌宠现在支持更长的完整角色动画。schema3素材采用后台六帧有界队列和累计源时间线，减少长片段整段预载与迟到回调造成的播放拖慢；旧schema1/2包继续使用原有约束。

- 新增长动画格式：512/720画布，每段8–240帧、20–200ms/帧、最长12秒，完整15动作及可选挠头。循环动作可提供进入/中段/尾部范围。普通状态只保留最新待播项；确认、失败及用户主动操作仍可及时打断。
- 长点击动作按实际片段结束恢复，避免原3.2秒计时提前截断。隐藏取消后台读取，恢复时重播当前动作。
- 默认素材更新为薄荷星伴1.5.0：仅idle替换为视频的80个正向原帧，约3.33秒，完成尺度稳定、脚底定位和透明处理。其余15段沿用1.4.0。
- 默认下载提供512和720画布两档。512档保留旧动作原文件；720档待机使用720母版，其他旧动作由512统一放大，不增加原始细节。角色继续署名Buddy娘，CC-BY-4.0；独立机器人模板仍为CC0。

## 保留与限制

人物开关、小卡收起、独立胶囊、仅卡片、积分、用户点击签到、WorkBuddy会话跳转、原蓝色图标及自启偏好继续保留。更新程序不会自动替换自选素材；使用新待机请另下载默认1.5.0并启用。旧程序不能导入schema3，请先更新程序。

待机首尾仍有嘴型和局部细节变化，不是完全无缝循环；其他动作未重制，先前挥手关节验证稿未采用。这不是全套角色动效重做完成的声明。

## 验证

本机170项回归通过；冻结程序检查覆盖Hook采集、PowerShell转发、GUI、素材导入、卡片层级和会话跳转。100%/150%原生待机窗口各连续播放约3.6轮；小卡收起保留人物、人物收成胶囊/恢复、隐藏停播及工作/待机切换通过。合成隔离场景不代表真实WorkBuddy新增事件已全部联调。发布前另检查Windows CI、最终冻结安装包、两档素材及下载摘要。
