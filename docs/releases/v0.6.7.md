# v0.6.7 · 稳定性与后台性能（待发布）

- 更新就绪后点击“稍后”暂停本次自动安装，等待编辑结束的回调也会取消；已下载包仍可手动安装。
- 任务过期后明确显示“状态待确认”，恢复休闲资格但不制造完成结果；真实审批、等待输入和失败提示继续优先。
- 记住同轮已结束工具，拒绝迟到的开始及重复结束事件；新轮次重置，保留并行工具处理。
- 兼容WorkBuddy5.9.3中SessionStart晚于UserPromptSubmit的真实顺序，避免启动通知抹除任务状态。
- 角色校验结果按文件签名缓存；文件变化或显式启用时重验，重复打开右键菜单不再反复哈希整套GIF。
- 诊断状态改由单一后台线程合并写入；状态变化及时更新，稳定状态每15秒心跳，启动就绪信号保留。
- 本机统计增量解析追加日志；处理半行、文件替换、截断和预算续读，不缓存正文。
- 同步当前基线与双角色版本，增加只输出事件覆盖汇总的真实联调工具。

薄荷星伴2.0.0与蓝色小鱼1.0.1的GIF保持原字节。版本号已用于开发构建，不代表已经发布到GitHub Releases。验证结果与真实事件边界见[兼容性记录](../compatibility.md)和[验收步骤](../qa/live-events.md)。
