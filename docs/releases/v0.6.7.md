# v0.6.7 · 本机统计兼容修复

- 本机统计按实际数据库结构读取，缺少自定义标题、模型、上下文、更新时间或删除标记等辅助字段时仍可统计已有用量。
- 缺少用量表或账单字段时明确说明，不把无法读取当成零消耗。
- 分别提示数据库尚未初始化、占用、访问权限及无法识别格式；小卡提示与数据页保持一致。
- 后台统计失败时清除旧显示，保留账户余额独立查询。
- 清理历史兼容性待办表述，保留功能范围与实际测试记录。

图片中的通用提示只能证明数据库查询失败，无法单凭截图确认某台电脑具体缺少哪个字段。更新后仍不能读取时，请提供 WorkBuddy 版本及数据页的具体提示，无需提交数据库或对话正文。
