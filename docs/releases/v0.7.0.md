# WorkBuddy Desktop Pet v0.7.0

新增白发龙角女仆，统一看板、菜单与显示方式。

- **第三套内置角色**：保留薄荷星伴与蓝色小鱼，新增18个动作标识的白发龙角女仆。每段30帧720×720透明GIF保持原始字节和时序；按用户选择，思考复用为工作、盘腿坐作为基础待机。更新保留当前角色。
- **更多随机待机**：闲置18–40秒后，从当前角色实际提供的休闲与待机动作中随机选择，避免连续重复。新角色包含睡觉和鞠躬；单次动作播完结束，真实任务及时抢占。过期的思考状态不再阻塞闲置。
- **统一看板**：胶囊直接进入概览、用量、角色和设置，取消多层展开。右键精简为主要操作，角色使用二级菜单；显示方式统一为桌宠＋胶囊、桌宠＋积分、仅胶囊。
- **灰白工具界面**：参考Emil Kowalski公开设计指南，以PySide6独立实现。固定导航和保存入口、可见键盘焦点、数字对齐、原位刷新与保存反馈。鼠标展开看板160ms淡入，尊重Windows系统动画偏好；键盘和高频页面切换即时响应。
- **交互修复**：打开用量标签自动刷新，快速筛选继续使用已有的结果防串逻辑；仅胶囊打开看板及重启均保留人物隐藏状态。

下载同页的 `workbuddy-desktop-pet-0.7.0-windows-x64-setup.exe`，按当前用户安装向导完成安装或升级。无需Python、无需重新导入内置角色。已有授权、导入素材和角色选择继续保留。ZIP便携包与SHA256校验文件同时提供。

新角色由用户授权本项目发布，并未声明通用再分发许可。原两套素材的署名与许可不变。角色GIF展示与合成事件测试不代表所有WorkBuddy版本的真实任务事件均已验证。

本地验证：197项自动回归、冻结程序采集与GUI、三个内置角色、两种原生缩放下每段三轮动画及关键动作切换通过。正式发布以前还由Windows CI执行安装、升级与卸载检查。
