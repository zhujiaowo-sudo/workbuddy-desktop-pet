# 独立胶囊与待机小动作 Implementation Plan

**Goal:** 胶囊独立贴底可恢复人物，待机眨眼/挠头自然且不覆盖真实任务。
**Architecture:** 纯placement函数恢复位置；Controller分离独立胶囊和人物联动模式；共享右键菜单；独立AmbientDirector调度可选动作；素材保留15必填动作。
**Tech Stack:** Python3.12、PySide6、Pillow、imagegen、pytest、PyInstaller。
**Spec:** docs/plans/2026-10-28-detached-capsule-idle-design.md。

## Global Constraints

- 用户已确认恢复时整组上移，15必填+可选挠头。
- 不改积分/签到授权，不发送聊天，不更换应用图标，不开启自启。
- 每项新功能检查旧功能冲突；发现新取舍先交给用户判断。

## Review Focus

- 胶囊尺寸变化/重启也须贴底不跳回隐藏人物位置。
- 仅卡片不因展开被取消；右键显式显示才退出仅卡片。
- 挠头不改变任务状态，不饿死已有长休闲计划。
- 多会话任一忙碌、菜单/拖动/隐藏均停止待机动作。
- 用户确认完整高清包7200万解码像素，轻量/旧包6400万；旧15动作包仍可导入。
