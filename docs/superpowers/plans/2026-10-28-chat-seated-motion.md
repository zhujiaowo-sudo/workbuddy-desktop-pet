# 聊天与动画修正 Implementation Plan

> 沿用用户直接开发方式，本会话实施。

**Goal:** 修复聊天默认通道，工作时坐下正向使用电脑，点击动作平滑无叠加弹跳。
**Architecture:** 固定目的relay与文本聊天解析独立；UI管理授权和请求代次；动画播放器管理过渡，素材生成器与源图分离。
**Tech Stack:** Python3.12、PySide6、Pillow、imagegen、pytest、PyInstaller。
**Spec:** docs/plans/2026-10-28-chat-seated-motion-design.md。

## Global Constraints

- 仅用户点击发送时调用模型；固定路径、文本消息、无工具，不自动重试。
- 其他用户本机聊天授权默认关闭；本机用户已明确同意。
- 原素材保留、署名及AI派生改动明确，用户大小与设置保留。

## Review Focus

- 取消/新请求不能接收上一个迟到回复：Task 1。
- 断线、授权失效与模型未知不能创建重复付费请求：Task 1。
- WorkBuddy配置多种结构与禁用模型：Task 1只选已确认可用文本模型。
- 点击期间素材与窗口双重运动、隐藏恢复及跨动作跳位：Task 2。
- 坐姿素材边缘杂点、帧间桌子移动、显示器方向错误：Task 2技术检查与目视预览。

### Task 1：聊天

- [ ] 添加chat_config/chat固定目的与受限请求合同，读取静态接口和只读配置验证。
- [ ] 新本机聊天默认入口、授权开关、模型选择与明确诊断；保留CLI/API配置。
- [ ] 合成测试模型、文本、授权、无工具、取消与超时；不自动发送真实模型请求。

### Task 2：动画

- [ ] 保存透明坐姿打字源图、生成来源和署名，提取/注册可播放帧并构建两档新素材。
- [ ] 去除abs(sin)竖向弹跳及双层运动，加入动作切换平滑过渡。
- [ ] 验证稳定桌椅/胶囊、正向屏幕、隐藏停播和连续点击。

### Task 3：交付

- [ ] 完整回归、原生预览、冻结验证与本机更新。
- [ ] 更新说明、代码、素材和模板；Windows CI通过后发布v0.5.1，核验公开下载。
