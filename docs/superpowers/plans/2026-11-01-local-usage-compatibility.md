# 本机统计兼容修复计划
用户要求修复异机本机记录不可用并清理历史兼容性待办措辞。
1. local_data.py 根据PRAGMA table_info读取已知表结构。id/session_id/credit_json是统计必需字段；标题、模型、上下文、排序及删除标记可缺省，不猜未知账单字段。
2. 区分尚未初始化、缺少统计结构、锁定、权限、损坏及其他数据库错误；只读访问不复制、不修改WorkBuddy数据库。
3. 测试精简schema、缺用量字段、中文路径、占用、损坏和原有统计去重/时区/只读行为。
4. 卡片沿用具体失败说明，后台异常清除旧统计。文档去除历史待办措辞，不增加未经支持的已验证结论。
5. 回归、构建与发布检查；异机具体原因以该电脑版本/诊断结果为准。
