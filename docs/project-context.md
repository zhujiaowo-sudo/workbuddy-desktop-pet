## 已确认的交互约定

- 右键只有一个人物开关：显示人物时为“收成胶囊”，隐藏时为“显示桌宠”。前者隐藏人物，保留可独立拖动的胶囊；菜单另有“退出桌宠”。
- 数据小卡的“−”只缩卡片，保留人物。卡片层级与人物显隐分别保存，不可混为同一操作。
- 胶囊位于人物实际可见轮廓上方8个逻辑像素；数据小卡和详细面板也在人物上方居中。忽略素材透明留白，按整段动画轮廓定位。
- 隐藏人物的胶囊可贴近屏幕可用区域底部；恢复人物时整组上移以完整显示，保持胶囊在人物上方。“重置位置”回主屏右下角并保留模式。
- 胶囊外围透明、会话文字与积分加粗，积分只显示向下取整的数字，宽度随数字长度调整；左侧快捷圆钮可设为签到、官网、自定义 HTTP(S) 网页或刷新。
- 左键人物弹出短句并播放互动；任务中使用坐姿电脑动画，休闲可坐姿玩手机/吃零食等，道具朝向人物。常态眨眼，偶尔挠头；真实任务与审批提示优先。
- 应用、任务栏、托盘图标固定为原始蓝色小搭子，与可更换人物素材分离。默认不启用开机启动。

## 接入和授权范围

- 首次自动检测 WorkBuddy 安装位置；用户在连接引导确认后完成本地状态插件绑定及勾选的查询授权。保留其他插件、设置和审批决定。
- 余额查询与签到分别授权。本机连接票据仅用于本机握手，不上传或记录；账户请求由 WorkBuddy 转发。启动、定时刷新和跨日只能查询签到状态，**领取必须由用户点击签到按钮触发**，不自动领取、不盲目重试领取。
- 桌宠内置聊天已移除。CLI 登录和本机聊天转发曾无法复用主程序会话，最终按用户决定改为跳转 WorkBuddy；不要重新加入模型设置、请求或凭据提取。
- 已实测主要任务开始、工具调用和完成事件；审批、失败、等待输入和子任务仍需补充真实事件验证。不能把合成测试结果表述为真实接入已验证。
- 自动更新在启动后及每6小时检查正式版本；展示版本与说明，用户确认后下载、校验、安装并重启。支持进度、取消、下载重试、稍后安装及失败回退，保留设置与素材。见[更新说明](updating.md)。

## 素材与动画维护

- 完整新版包保留 **15个必填动作**，另可选 `idle_scratch`；旧15段包继续兼容，可选扩展需新版程序。公开格式、尺寸、帧数、命名、导入约束以[素材制作说明](materials.md)和[Schema](pet-pack.schema.json)为准。
- schema1/2保持旧约束：schema2轻量256、高清512，每段8–16帧、40–200ms，高清全包72M像素。schema3新增512/720、8–240帧、20–200ms、每段最多12秒和有界后台队列。详见素材说明；不能用新限制默许旧包超限。
- 默认“薄荷星伴”须按 Buddy娘 **CC-BY-4.0** 署名；蓝色机器人创作模板独立使用 CC0。不要混淆许可，见[NOTICE](../NOTICE.md)。
- v1.4.0待机与挠头共用基础身体，眼睛局部切换、手臂按固定部件旋转；播放器按素材实际帧播放，取消整图叠帧和动作间淡化，避免多重五官及残影。
- 用户曾指出脸/腿变形、胳膊大小不一及重叠。以后动画改动必须检查**完整循环、动作衔接、原生渲染、共同身体结构**；静态关键帧或元数据通过不能代替动态验收。草稿不得当成修复成品交付。

## 本机待机替换（2026-10-28）

用户明确要求直接替换本机桌宠。已通过170项回归和冻结程序导入/GUI/Hook验证，沿用现有安装位置完成0.6.2→0.6.3更新并重启；实际运行状态为idle且新动画已加载。大小、位置、卡片位置、自启及账户授权开关保持。旧程序、设置备份及旧素材保留，没有改动WorkBuddy本身或其他桌宠。

本机素材源为用户提供的HappyHorse视频，经稳定头盔特征、脚底注册、白底透明处理和正向选段，输出80帧/3333ms。首尾嘴型与细节仍有差异，用户在知悉这一限制后明确要求安装。先前分件和挥手验证稿因关节问题未通过，不得重新启用为正式素材。其余15段未重制。

这是本机替换，不代表已完成全部动效重制或公开发布。本机预览曾使用0.6.3；此次正式发布后对本机执行同号安装同步，以避免仅靠更新器跳过同号包。后续自动更新版本需高于0.6.3。
