# 项目上下文与已确认约定

更新于2026-11-01。当前基线为v0.7.0，历史实现以各版本[发布记录](releases/v0.7.0.md)和[兼容性记录](compatibility.md)为准。

## 产品与工程

- 公开仓库：https://github.com/zhujiaowo-sudo/workbuddy-desktop-pet 。仅面向WorkBuddy、Windows10/11 x64，不添加其他助手接入。
- Python3.12、PySide6、Pillow、PyInstaller、Inno Setup7。事件采集、纯状态转换、界面保持分离。
- v0.6.8引入当前用户EXE安装向导；首次集中确认接入、余额、签到和可选自启，升级沿用已有授权。卸载只移除本项目的接入与启动项，保留用户数据。ZIP更新保留卸载维护文件。
- v0.6.7对本机数据库按实际字段构造只读查询，缺少辅助字段仍可统计；缺少用量字段不冒报零，区分未初始化、结构差异、占用及访问问题。异机5.9.3的具体问题不能仅凭截图认定原因。

## 当前角色与动画

- 内置薄荷星伴2.0.0、蓝色小鱼1.0.1、白发龙角女仆1.0.0。新增角色不替换现有角色选择，不清空外部素材。
- 薄荷星伴须保留Buddy娘/CC-BY-4.0署名。蓝色小鱼和白发龙角女仆由用户授权本项目发布，原包未声明通用再分发许可；不混淆许可。见[NOTICE](../NOTICE.md)。
- 新角色为用户提供的720×720、每段30帧原始GIF，18个动作标识；用户明确选择思考复用为工作、盘腿坐作为基础待机。原字节和时序保留，不拼接关节。
- 无有效任务18–40秒后，从当前角色支持的休闲／待机动作中随机选择，避免连续重复。循环动作6–10秒后在完整循环退出；非循环动作按原片段结束。任务、审批、点击、拖动、菜单和展开看板具有相应优先级。
- 思考／工作长时间无新事件按有效状态退回闲置显示，不据此判定任务完成；真实等待确认、输入和失败仍保留提示优先级。
- schema1/2输入限制不变。schema3支持512/720、8–240帧、20–500ms、单段最多12秒、有界后台队列；15必填，可选idle_scratch、idle_sleep、idle_bow（后两者需0.7.0）。见[规范](materials.md)与[Schema](pet-pack.schema.json)。
- 用户曾指出脸、腿和关节比例问题。任何动画改动必须检查完整循环、动作切换、原生渲染与身体结构，静态关键帧或元数据不能代替动态验收。旧视频待机与分件草稿不重新启用。

## 已批准的界面与交互

- 用户同意中性工具风格、统一看板、精简右键菜单；追加要求参考Emil Kowalski项目。实际检索并参考emilkowalski/skills和Sonner，采用独立Qt实现，不引入React依赖。
- 胶囊直接打开概览／用量／角色／设置四页看板；固定导航，设置保存按钮固定在标题栏。右上角×和Esc收起看板，保留人物显示方式。主动打开的详细页不因闲置而自动收走。
- 右键只有主要入口：打开WorkBuddy、数据看板、角色二级菜单、显示二级菜单、设置、退出。显示为桌宠＋胶囊／桌宠＋积分／仅胶囊三个互斥选项。仅胶囊打开看板及重启不恢复人物，隐藏时停止解码。
- 黑白灰界面；高频标签切换和键盘操作即时响应。鼠标展开160ms淡入，尊重Windows系统动画偏好；关闭中断淡入并恢复不透明。
- 胶囊和面板位于人物可见轮廓上方8逻辑像素，忽略素材透明留白。隐藏时胶囊可独立拖动、贴底；恢复人物时调整整组位置以避免出屏。重置位置保留显示模式。
- 积分徽标向下取整，宽度按数字长度调整；极简模式使用圆形徽标。左侧快捷按钮可选签到、官网、自定义HTTP(S)地址或刷新。
- 点击人物轮换互动。拖动采用整个角色的拎起与放下效果，不改变关节。任务／审批提示优先，动作不修改积分和任务结果。
- 应用、任务栏、托盘保留独立的蓝色小搭子图标，不随角色切换。默认不启用登录自启。

## 授权、数据与真实接入边界

- 保留WorkBuddy其他插件与审批决定。余额查询和签到各自授权；后台仅查询签到，领取必须由用户点击，不自动领取、不盲目重试。
- 不加入桌宠聊天转发、模型配置或凭据提取；会话入口只打开WorkBuddy相应会话，没有会话则打开主程序。
- 主要任务开始、工具调用、完成事件已实测；审批、失败、输入和子任务依据客户端事件展示。合成测试不能表述为所有版本真实接入均已验证。
- 账户余额、本机消耗与事件为独立通路，本机统计不是完整账户账单。快速筛选只呈现最新选择的结果，失败保留明确说明，不冒报为零。
- 更新在启动及每6小时检查正式版本，确认后下载、校验、安装、重启；保留授权、设置和素材，支持回退。用户明确要求保留旧程序回退目录。
