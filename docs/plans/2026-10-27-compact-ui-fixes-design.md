# 紧凑卡片与人物停靠修正

日期：2026-10-27。依据用户5项截图反馈及补充，沿用直接开发方式。

- 胶囊与积分徽标合为同一紧凑窗口，整组居中停靠人物正上方，间距8个逻辑像素。人物拖动、尺寸变化及展开/收起均重新计算停靠位置；靠近屏幕边缘时整组向屏幕内让位，确保仍然居中且胶囊位于上方。空间充足时收放不移动人物。完整卡片停靠人物侧边、底部对齐。仅卡片时窗口独立定位。
- 完整卡片从430px宽缩为360×440逻辑像素；胶囊为单行，旁边显示真实剩余积分。WorkBuddy5.9.2普通文件没有余额，但本地WBIPC转发通道可在用户明确授权后只读查询积分摘要。该授权在设置中独立控制，默认关闭；本机连接票据只用于双向HMAC握手，不上传、不记录，也不提取登录token。只允许固定余额查询路径，返回完整摘要后按客户端同样规则汇总，不通过消耗记录估算。失败显示待同步。
- 人物右键弹出任务详情、积分与模型、聊天、角色与素材、设置与连接及收起菜单。弹出菜单不展开卡片，用户选择后打开对应页面。
- 收起按钮放在右上角。采用独立QTabBar与QStackedWidget，移除原生标签底线，分界线和标签栏各自占用布局区域；页面背景不透明，窗口每次重绘先清理旧帧，避免残影与穿透。
- 页面过长时只垂直滚动。保持已有事件、统计、素材、聊天与接入逻辑不变。

验收：合成界面覆盖人物100/160/240尺寸、屏幕边界、反复展开收起、菜单页面选择、每个页面的布局/重绘以及余额。验证固定只读请求、双向身份校验、未知与0值区别；原49项回归继续通过。交付v0.2.1程序包，更新当前运行程序及GitHub仓库。
