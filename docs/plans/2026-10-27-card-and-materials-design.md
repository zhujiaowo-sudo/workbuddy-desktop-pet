# 卡片、统计与开放角色包设计

日期：2026-10-27。用户已同意补充动画播放器、素材导入管理、公开模板，以及本地统计、胶囊卡片、会话跳转和仅卡片四项功能；沿用直接开发方式。

## 范围与选择

采用本地角色库，支持 ZIP 和文件夹导入，不建设公共上传服务器。素材包可由作者自行分享。参考白龙项目的清单、分档素材和卡片独立思路，代码与默认形象独立实现。默认“小搭子”为现有原创蓝白机器人，不依赖下载。另提供可导入的轻量和高清示例包。

## 角色包

schema=1 的 manifest.json，包括 id、name、author、version、license、quality（light/hd）、actions。action 键为 idle/thinking/working/waiting/review/done/failed，idle 必填，其他缺失回退 idle。动作使用透明 PNG、GIF 或 WebP；单段最多 300 帧，画布边长不超过 1024、解码像素总量不超过 6400 万、总展开体积不超过 128 MiB、最多 64 个文件。ZIP 拒绝越界路径、符号链接、重复名称和非素材文件。清单可附文件 SHA-256；导入生成自身内容摘要，临时目录验证成功后才发布。损坏包不会切换当前角色。

播放器遵循帧时长，切换状态重置动作；隐藏时停止计时。角色库支持预览、启用、删除、模板导出。删除使用中的包先回到默认角色或仅卡片，释放播放器后删除库内受管理文件；不会删除源文件夹。核心程序包含矢量默认角色，无需下载人物素材即可运行。

## 本地数据与统计

以只读 SQLite 读取 .workbuddy/workbuddy.db 的 sessions 和 session_usage；积分按 credit_json 的请求ID映射汇总，used/size 仅为上下文用量。请求模型和时间从对应历史 JSONL 元数据读取，去重后关联请求ID。未知时间仅计入全部统计，未知模型单独显示。Auto 无实际模型元数据时显示 Auto/实际模型未知。不把会话配置模型冒充逐请求模型；不读取登录或 API 密钥。统计页面支持全部/7天/30天和模型汇总，标注本机记录及缺失数据。读取在后台完成，时间和模型索引只留内存，避免把对话正文复制到桌宠数据库。

## 胶囊与集成面板

一个卡片窗口内含详情/数据/聊天/素材/设置页面；可固定胶囊或开启闲置自动收起（默认30秒）。工作、未读提醒、焦点输入或正在操作时不自动收起。点击人物打开卡片。仅卡片时卡片可拖动，托盘可恢复，角色窗口隐藏；现有显示位置设置保持兼容。

## 会话跳转

会话名来自本地 sessions.custom_title/title；点击以系统协议打开 workbuddy://chat/<URL编码ID>。只允许有效会话ID字符串，失败时提示并保留打开主程序入口。当前协议以 WorkBuddy5.9.2 源码和 Windows 注册为兼容依据。

## 聊天

聊天嵌入同一面板。优先验证随 WorkBuddy 安装的 CLI 无工具文本模式；不连接未公开的宿主内部IPC、不导出登录凭据、不自动审批。不将独立闲聊冒充已有桌面任务会话。CLI通道不可用时明确显示错误，保留打开对应WorkBuddy会话及复制草稿入口。若本机无法完成收发，交付说明中保留该限制，不把界面展示当作已打通。

## 验收

合成SQLite/历史元数据覆盖请求去重、日期、未知模型、删除会话及上下文不误算；合成素材覆盖合法导入、坏图、越界ZIP、缺动作回退及删除边界；Qt测试覆盖胶囊切换、仅卡片、集成设置与播放器暂停。运行实际只读统计、真实深链与聊天通道测试，截图验证后打包；不提交本机数据或凭据。
