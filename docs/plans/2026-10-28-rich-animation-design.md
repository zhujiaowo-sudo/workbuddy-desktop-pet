# 多状态互动与完整素材包

沿用用户“直接开发”的执行要求。保留薄荷星伴、224大小、固定蓝色应用图标、账户授权及卡片布局。

## 方案选择

采用“兼容旧包 + 完整互动包 + 本地动作调度”。只扩展旧7状态包无法让作者区分点击与休闲；强制所有旧包升级会使现有角色失效。schema=1继续可导入，schema=2用于15段完整互动包。默认薄荷包由用户已有CC-BY-4.0素材派生，新增程序绘制的道具与运动关键帧，明确署名和改动。

## 行为

- 7任务状态保持真实事件语义，working显示电脑、键盘操作与进度光点。
- 左击轮换招手、比心、害羞、惊讶4种反应和短句，约3秒；拖动不触发。真实确认/等待/失败提示优先。点击与休闲不创建任务事件。
- 连续无任务45–110秒后，随机播放吃零食、玩手机、伸懒腰、听音乐6–10秒，避免连续重复。完成后至少停留12秒再允许休闲；思考/工作/等待/审批/失败或其他会话仍忙时不休闲。新任务立即打断休闲；隐藏、仅卡片、拖动、打开菜单或详细面板时暂停并重新计时。
- 旧包缺扩展动作时选择相近基础表情，并用程序道具/轻摆补充；完整包使用作者提供动作，不重复叠加道具。内置静态形象也有电脑及休闲道具。
- 休闲不更改胶囊任务文字，不遮盖提醒。动作结束恢复最新业务状态。帧之间不重新停靠；整段使用稳定包络，避免胶囊抖动。

## 素材规范

schema=2必须15个标识：idle/thinking/working/waiting/review/done/failed，click_wave/click_heart/click_shy/click_surprised，leisure_snack/leisure_phone/leisure_stretch/leisure_music。

每项一个独立动画文件，`actions/<标识>.webp|png|gif`，透明背景；light=256×256，hd=512×512；统一画布、脚底基线、人物比例；每段8–16帧，每帧40–200ms，建议16帧×80ms。PNG须APNG，静态PNG不能充当完整动作。7基础状态均有动画，working须表现使用电脑。共15段，manifest+15文件=16项；禁止多个标识复用一个文件。任务循环与4休闲循环，done/failed/4点击不循环。仍保留128MiB/64文件/6400万总解码像素的安全限制。

导入严格检查数量、命名、尺寸、帧数、透明度、循环及总预算。schema=1仍允许静态idle最小包，标注兼容模式。素材界面新增动作选择预览和完整度说明；导出15动作CC0原创机器人模板，根目录说明通过单独文档提供，ZIP保持只含素材与清单。

## 验证与交付

合成时间与随机源验证不重复、打断、隐藏、所有会话忙碌及结束恢复；素材测试覆盖旧包兼容和新包每类错误；检查程序绘制动画不同帧有实际变化。生成薄荷轻量/高清派生包和公开模板，原ZIP不变。运行Qt与冻结验证，更新本机角色及程序、保留其他设置，推送并发布v0.5.0。
