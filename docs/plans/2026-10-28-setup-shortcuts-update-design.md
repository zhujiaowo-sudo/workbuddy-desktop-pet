# 首次绑定、胶囊交互与自动更新

按用户已授权的直接开发方式实施。保留外部聊天、固定蓝色应用图标、素材独立下载、用户大小和自启选择。

首次启动自动从运行进程、协议注册、32/64 位安装注册表及常用目录定位 WorkBuddy。显示一次清楚的绑定页，用户点击完成后安装本地状态插件并按勾选授权读取余额、查询签到；只有点击签到才领取。已有授权保持，失败可重试，不改变 WorkBuddy 审批规则。无登录或未启动时解释原因并后台重试。

右键收成胶囊同时隐藏人物；点击胶囊展开恢复人物，永久仅卡片设置独立。隐藏停止动画，胶囊仍可拖动。右键菜单增加退出。左圆按钮可设签到、官网、自定义 HTTP(S) 网页、刷新；网页只有点击才打开。剩余积分向下取整，胶囊余额框按字体测量自适应宽度。

薄荷手机/零食改为真正坐姿源图，手机背面朝观众、屏幕朝人物；手部与面部局部动画，身体、椅子、脚底固定，保持作者与 CC-BY-4.0 署名。

更新源使用本项目 GitHub 正式 Releases latest API，启动 10 秒后及每 6 小时后台检查，可关闭自动检查或手动检查。只接受较新三段正式版本、同仓库对应版本 ZIP 与 SHA256SUMS。提示版本和纯文本更新内容；用户确认后后台下载，进度/取消/最多三次网络重试，完整大小与 SHA-256 校验。用户可继续使用，准备好后再点击重启安装。

更新 ZIP 严格验证路径、重复文件、符号链接、文件数/解压大小和程序结构，在安装目录旁完整解压。独立 PowerShell 助手在桌宠退出后交换目录，保留旧目录备份；失败回退旧版并重启。设置、素材、事件数据在用户目录不搬迁；安装位置不变，快捷方式有效。不可写目录明确提示手动下载。更新检查不访问 WorkBuddy 账户或发送模型请求。旧版 0.5.1 尚无更新器，首次需安装本版。

验证覆盖新旧设置迁移、授权不静默开启、注册表/进程候选、胶囊恢复、快捷 URL 限制、整数宽度；更新版本比较、来源、下载重试/取消/损坏、ZIP 安全、原生目录交换与回退、冻结包。公开 CI 与发布后再验证匿名下载。
