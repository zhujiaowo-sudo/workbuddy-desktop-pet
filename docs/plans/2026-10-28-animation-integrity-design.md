# 动画结构修复与收起入口分离

用户明确要求：消除脸/腿变形；右键收起/显示合并为同一按钮；小卡“−”只缩小卡片、保留人物。既有“发现取舍交用户判断”继续执行，本次三项均有明确行为要求，无需再次确认。

根因：播放器以不同轮廓图片叠加模拟中间帧，眨眼导出也混合不同五官；挠头上身遮罩跨过腿部，基准身体又与idle不同。修复采用原始帧直接显示，不叠加跨帧或跨动作图片。新默认idle/scratch共享唯一身体、头型和腿，眼睛变体与刚性手臂分层合成，用真实关节角度生成中间姿势，不对完整人物做混合/拉伸。重复睁眼帧使用APNG保存，保持8–16帧、40–200ms规范，无需伪造细微变化。

初稿分层部件的比例及拼接仍不合格，用户指出后重新修订源图、固定袖宽/手套比例和肩点，检查完整抬手/放下过程，而非以初稿或局部截图验收。每次PetWindow重绘先清空透明画布，防止旧姿势像素残留。

| 交互/兼容项 | 修正 |
| --- | --- |
| 两个同义右键按钮 | 合并为同一个Action，人物可见时收起，隐藏时显示 |
| 小卡−错误隐藏人物 | 卡片层级与人物可见性分离，保留人物+胶囊 |
| 旧“平滑”叠图带来五官重影 | 直接播放真实帧，平滑由实际中间姿势提供 |
| 挠头腿部拼接/手臂大小不一 | 共用基础身体，固定腿、关节长度与袖宽，匹配手套比例 |
| 永久仅卡片/贴底/重启 | 保留原能力，仅显式人物开关才退出仅卡片 |
| 旧包/签到/聊天/更新 | 原帧可播放，格式/授权不变，执行完整回归 |

右键仅一项人物开关：人物显示时“收成胶囊”，人物隐藏时“显示桌宠”，以人物可见性判断。小卡“−”只切换卡片层级，因此支持“人物+胶囊”。右键收成胶囊才进入独立胶囊，保留贴底拖动和恢复时整组上移。永久仅卡片仍需明确“显示桌宠”才退出，提示放在菜单说明。

兼容检查覆盖：单一开关/双击/只缩卡片/永久仅卡片/贴底恢复/持久化；任务、点击、休闲和隐藏优先级；旧包按原帧播放；72M高清上限；全部动作循环首尾及转换；签到拖动、聊天跳转和自动更新。动态验收必须输出全部16动作帧表、循环预览和时间采样的播放器帧，不能只检查几个静态截图。
