# 制作与分享自己的 WorkBuddy 桌宠

v0.2.0 使用独立的本地角色库。设置、统计、卡片和 WorkBuddy 接入均不依赖人物动画。原创默认“小搭子”由程序绘制，无需下载；可选轻量包为256px、高清包为512px，每套含7种工作状态。

## 使用素材

展开卡片 → 素材 → 导入 ZIP 或导入文件夹。导入成功后先预览，再点击“启用所选角色”。本地文件不会上传服务器；导入只复制素材，不移动或修改源目录。

选择“仅显示卡片”隐藏人物并释放动画帧。删除正在使用的素材时自动切到仅卡片，保留设置与 WorkBuddy 接入；也可随时启用内置角色。默认素材的下载会校验固定 SHA-256；下载失败时仍可用内置角色或本地导入。

## 最小可用包

在素材页点击“导出创作模板”，得到可直接再次导入的 ZIP。解压后替换 idle.png、填写作者和许可，再将文件直接放在 ZIP 根目录：

```text
my-pet.zip
├─ manifest.json
└─ idle.png
```

manifest.json 示例：

```json
{
  "schema": 1,
  "id": "my-pet",
  "name": "我的桌宠",
  "author": "作者名称",
  "version": "1.0.0",
  "license": "CC0-1.0",
  "quality": "light",
  "actions": {
    "idle": {"file": "idle.png", "loop": true},
    "working": {"file": "working.webp", "loop": true},
    "done": {"file": "done.webp", "loop": false}
  }
}
```

示例中列出的文件均须存在；如果只有待机素材，删去 working 和 done 两项。idle 必填，其他动作缺失时使用 idle。license 请填写你实际授予的许可；模板中的示例不替第三方素材授予许可。

## 动作与制作要求

| 标识 | 状态 | 建议 |
|---|---|---|
| idle | 空闲 | 呼吸、眨眼，循环 |
| thinking | 思考 | 托腮、整理思路，循环 |
| working | 执行任务 | 打字、翻资料，循环 |
| waiting | 等待回复 | 看向用户，循环 |
| review | 等待确认 | 举手提示，循环 |
| done | 完成 | 微笑、庆祝，可不循环 |
| failed | 失败 | 困惑、提醒，可不循环 |

使用透明背景，保持各动作画布、角色大小和脚底位置一致。支持 PNG（静态或APNG）、GIF、动画WebP；优先透明WebP。尊重每帧时长，最短20ms，最长10秒；非循环动作停在末帧，业务状态变化时切换动作。状态准确性由卡片文字提供，缺少动画不会改变任务状态。

每个包最多64个文件、展开体积128 MiB；单边最多1024px，每段最多300帧；整包最多6400万解码像素。拒绝链接、越界路径、Windows保留文件名、重复名称、加密ZIP、脚本与可执行文件。清单最多64 KiB。ZIP中不要额外嵌套一层同名文件夹，也不要混入预览视频或制作工程文件。

可选 files 字段使用 `{"idle.webp":"64位SHA-256"}` 进行内容校验。导入时还会生成整个包的内容标识，重复导入相同包不会增加副本。程序接口见 `workbuddy_pet.materials.MaterialLibrary` 的 import_pack、list_packs、load、remove；这是本地 Python 接口，不开放网络端口。

正式结构约束见 [JSON Schema](pet-pack.schema.json)。清单 schema 为1，未来不兼容变更会使用新版本号。

## 分享和默认形象

把 ZIP 分享给其他用户即可，不需要账号或公共上传服务器。提供自己的作者名称、版本和许可；只分发有权分发的图像，不放入聊天记录、密钥或个人文件。

本项目独立绘制的“小搭子”示例人物图像以 CC0-1.0 提供，可作为自制角色的起点；该声明仅覆盖本项目原创默认形象及其导出图像，不覆盖白龙人物、第三方素材或整个程序代码。

源码环境运行 `python tools/create_pet_template.py` 可生成完整轻量、高清示例ZIP。它导出当前程序绘制形象，不调用图像生成服务。
