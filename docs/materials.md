# 桌宠素材制作、导入与分享规范

v0.5.1提供15动作完整互动包。默认形象为**薄荷星伴**，原作者**Buddy娘**，CC-BY-4.0；互动版新增程序绘制的电脑、零食、手机、爱心和音符，以及运动关键帧。核心程序自带静态首帧；人物动画仍独立下载，仅卡片不依赖动画。

## 导入与管理

卡片 → 素材 → 导入ZIP或文件夹 → 选择动作预览 → 启用所选角色。导入先检查整包，失败不会替换正在使用的角色。提供15项动作预览，显示“完整互动”或“兼容包”及动作数量。文件只复制进本机角色库，不上传服务器、不修改原文件。

“下载默认轻量包/高清包”会校验固定SHA-256，下载完成后仍需点启用。删除正在使用的素材会切到仅卡片；可再次启用内置形象，卡片、统计、设置与WorkBuddy接入保留。

## 两类素材包及数量要求

| 类型 | 清单版本 | 动画数量 | 用途 |
|---|---|---|---|
| 完整互动包 | `schema: 2` | **恰好15段**，下表标识全部必需 | 推荐社区提交、公开分享及默认形象使用 |
| 旧版兼容包 | `schema: 1` | 1–7段，`idle`必需 | 继续使用旧素材，可只有静态待机 |

完整包通常是**1个manifest.json + 15个独立动画文件，共16个文件**。一个动作一个文件，不得把多个标识指向同一个文件。表情和动作集成在该段动画中，不需要另交一套表情贴图。旧包不会被强制升级，缺少互动段时使用相近表情和内置道具。

## 15个动作及触发规则

每行均需一段独立动画；文件基本名必须与标识完全一致，区分大小写。

| 标识 / 文件基本名 | 内容与表情要求 | 循环 |
|---|---|---|
| `idle` | 空闲：自然呼吸、眨眼，放松表情 | true |
| `thinking` | 思考：托腮、观察、整理思路 | true |
| `working` | 执行：**使用电脑**，推荐坐姿；屏幕朝向角色，键盘位于双手下，桌椅固定，手部需变化 | true |
| `waiting` | 等待回复：看向用户、轻挥手，耐心表情 | true |
| `review` | 等待确认：举手或提示，认真表情 | true |
| `done` | 完成：开心、庆祝、笑脸 | false |
| `failed` | 异常：困惑或轻沮丧，避免惊吓 | false |
| `click_wave` | 点击1：招手、开心回应 | false |
| `click_heart` | 点击2：比心、亲近笑脸 | false |
| `click_shy` | 点击3：害羞、脸红、轻轻侧身 | false |
| `click_surprised` | 点击4：惊讶、睁眼、轻弹跳 | false |
| `leisure_snack` | 休闲：吃零食，取食/咀嚼动作 | true |
| `leisure_phone` | 休闲：玩手机，滑动/点屏动作 | true |
| `leisure_stretch` | 休闲：伸懒腰、活动肩膀或左右舒展 | true |
| `leisure_music` | 休闲：听音乐、轻摆，可搭配音符 | true |

左键点击依次轮换4种反应，约3.2秒后恢复最新任务动作；拖动不触发互动，右键选择模块。确认、等待输入和失败状态优先于点击动画，不会覆盖其重要提示。

连续无任务45–110秒后随机播放一个休闲动作6–10秒，避免连续重复。完成后至少保留12秒完成状态；任何会话仍忙、待回复、待确认或失败时不休闲。新任务立即打断休闲。隐藏人物、仅卡片、拖动、菜单或详细面板打开时暂停并重新计时。休闲不改写任务状态文字、积分或提醒，不访问模型接口。

## 完整包的格式、尺寸和帧数（导入强制校验）

| 项目 | 要求 |
|---|---|
| 文件格式 | 动画WebP优先；支持APNG（扩展名`.png`）和动画GIF。静态PNG/WebP不符合完整包要求。GIF边缘透明度较粗，建议WebP |
| 透明背景 | 每一帧有透明区域及可见角色；不能用纯色背景或全透明帧 |
| 轻量 | `quality: "light"`；所有帧**256×256px** |
| 高清 | `quality: "hd"`；所有帧**512×512px** |
| 帧数 | 每段**8–16帧**，建议16帧；应有实际连续变化，不用同一静态图重复充数 |
| 帧时长 | 每帧**40–200ms**，建议80ms（12.5fps）；程序遵循文件帧时长并以约30fps平滑插值；点击推荐120–160ms/帧，工作动作可用8帧×160ms |
| 循环 | 必须与上表一致；休闲段循环6–10秒后由程序结束，点击段播放一次后短暂停留 |
| 构图 | 各段画布、角色比例和脚底基线一致；人物/道具不要贴边或截断；预留旋转、伸展空间 |
| 文件名 | `actions/<动作标识>.webp`，或同名`.png`/`.gif`；小写ASCII及下划线 |
| ZIP名 | 推荐`<角色id>-<light或hd>-v<版本>.zip`，例如`my-pet-hd-v1.0.0.zip` |

高清15段×16帧×512²=62,914,560解码像素，低于整包64,000,000上限。不要把轻量、高清合放一个包。循环次数以清单`loop`为准，文件内部循环设置不会代替清单。

清单可提供`anchor: [左, 上, 右, 下]`，坐标为原始画布像素，右/下不包含边界；它必须包住所有动画帧的可见轮廓（alpha>16）。用于跨动作保持胶囊位置稳定。点击段须固定脚底基线，避免整个人物上下跳；播放器有180ms切换过渡。工具导出的包已计算；替换素材后应重新计算或删除该字段，不能保留裁掉新动作的旧值。未提供时使用当前整段动画的稳定轮廓，帧之间不会逐帧跳动。

## 目录与清单

```text
my-pet-hd-v1.0.0.zip
├─ manifest.json
└─ actions/
   ├─ idle.webp
   ├─ thinking.webp
   ├─ working.webp
   ├─ waiting.webp
   ├─ review.webp
   ├─ done.webp
   ├─ failed.webp
   ├─ click_wave.webp
   ├─ click_heart.webp
   ├─ click_shy.webp
   ├─ click_surprised.webp
   ├─ leisure_snack.webp
   ├─ leisure_phone.webp
   ├─ leisure_stretch.webp
   └─ leisure_music.webp
```

完整清单见[可编辑示例](../examples/interactive-manifest.json)及[JSON Schema](pet-pack.schema.json)。必填`schema/id/name/author/version/license/quality/actions`；清单UTF-8，不超过64KiB。`id`推荐小写英文及连字符，如`mint-orbit`；`version`推荐`1.0.0`。作者、展示名及许可不能留空，许可填写你实际有权授予的条款。

可选`files`记录文件相对路径与64位小写SHA-256。修改图像后须更新摘要或删除`files`字段；错误摘要会拒绝导入。JSON Schema只描述清单，实际图片内容仍须通过程序解码检查。

ZIP根目录直接放manifest.json，不要额外嵌套同名顶层文件夹。每包最多64个文件、展开体积128MiB、总解码像素6400万。拒绝重复/越界路径、链接、目录联接、Windows保留文件名、加密ZIP、脚本及可执行文件。不要混入预览视频、PSD/工程文件、个人文件或聊天记录。

## 公开模板与提交前检查

素材页“导出15动作模板”可导出可直接再次导入的轻量ZIP，使用本项目原创小搭子机器人（CC0-1.0），**不会把薄荷形象标成CC0**。替换全部15个同名动画、填写作者/许可、更新摘要和包络后导入验证。

公开下载：[v0.6.0模板与动画附件](https://github.com/zhujiaowo-sudo/workbuddy-desktop-pet/releases/tag/v0.6.0)。提供轻量/高清模板2.0.1和薄荷互动包1.2.0，二者许可分别说明。

源码环境验证（只检查临时副本，不启用角色）：

```powershell
python tools/validate_pet_pack.py my-pet-hd-v1.0.0.zip
python tools/create_interactive_pack.py --output dist/materials
```

第一条输出检查结果、动作数和帧数；第二条导出两档原创机器人模板。`create_interactive_pack.py --source 原薄荷包.zip --catalog`用于维护默认薄荷派生下载，原ZIP保持不变。

分享ZIP即可供其他用户导入，不需要账号。目前提供的是**本地导入接口**，没有公共上传服务器；程序接口为`workbuddy_pet.materials.MaterialLibrary`的`import_pack/list_packs/load/remove`。社区公开分享请同时提供角色名、作者、版本、许可和预览图。需要发行到官方仓库附件的作品应先按完整包要求验证。

## 旧包与许可

schema=1沿用原7标识，idle必需，支持静态PNG、APNG、GIF、WebP；其他任务动作缺失回退idle。单边≤1024px、每段≤300帧；帧时长规范化为20ms–10秒；仍受全包安全上限约束。无需改名即可导入。新8个扩展标识只在schema=2中使用。

薄荷星伴原作者Buddy娘、CC-BY-4.0，互动版1.2.0派生自用户提供的1.0.1包，保留署名、许可链接及改动说明。工作、手机、零食采用真正坐姿，屏幕朝人物，身体/座椅/脚底固定，手部/面部局部变化。社区投稿的这三类动作也应满足同样构图要求，不用站姿叠加漂浮道具；格式、尺寸与15动作数量规范不变。源图及提示词见[生成记录](../art/mint-orbit/leisure-v1.2.0.md)。原包仍在[v0.3.1](https://github.com/zhujiaowo-sudo/workbuddy-desktop-pet/releases/tag/v0.3.1)。见[NOTICE](../NOTICE.md)。不要将该许可套用于白龙、其他角色或整个程序代码；只分发自己有权分发的图像。
