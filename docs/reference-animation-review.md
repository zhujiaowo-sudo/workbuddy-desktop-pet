# 动画方案与验收要点

本文整理本项目采用的动画约束；当前实现及实测结果以[素材规范](materials.md)、[兼容性记录](compatibility.md)和[2.0.0验收记录](qa/user-gifs-v2.0.0.json)为准。

## 动作与构图

- 固定画布，以头部、躯干尺度与脚底基线检查比例；不按每帧包围盒重新缩放人物。
- 使用素材实际提供的姿势和停留时间，不以整图淡化混合五官或肢体，不用重复帧冒充更高帧率。
- 检查完整循环、进入与收尾、动作切换和紧急打断；静态关键帧不能代替动态验收。
- 当前默认套装直接使用用户提供的16段透明GIF，保留原文件字节和时序。

## 播放与兼容

- schema1/2沿用各自输入限制；schema3支持更长动画，0.6.4起允许20–500ms的真实停留帧。
- 后台解码使用有界队列与非阻塞取消，避免一次将全部长动画解码并驻留内存。
- 播放时间从素材累计时间线推进，减少界面回调延迟造成的长期漂移。
- 单次互动按实际片段结束后恢复最新状态，确认、等待和失败提示可以打断互动。
- 可选中段循环协议保留进入和退出帧；当前默认GIF按作者完整片段播放。

## 界面验收

胶囊和卡片以统一可见包络定位；检查启动首帧、缩卡、隐藏恢复、快速切换与不同Windows缩放。动画检查使用隔离环境或合成事件，不将其描述为真实任务联动实测。
