# 软件更新

Windows 发布版在启动约 10 秒后及每 6 小时后台检查本项目 GitHub 正式 Releases，也可在设置点击“检查更新”；关闭“启动及每 6 小时检查新版本”后仍可手动检查。检查失败不会退出桌宠。预发布不作为自动升级目标，不会自动降级。

发现新版时显示版本号、更新内容和下载大小。点击“下载并更新”后显示字节进度，网络/完整性失败最多尝试 3 次，之后可手动重试。勾选“下载后自动安装并重启桌宠”时，准备完成自动安装；取消勾选则先下载、稍后点击“重启并安装”。下载中可取消，使用桌宠和 WorkBuddy 不受影响；素材导入或设置文本编辑未结束时暂缓自动重启。安装仅重启桌宠，不终止 WorkBuddy 任务。

仅从 `zhujiaowo-sudo/workbuddy-desktop-pet` 对应正式版本下载 `workbuddy-desktop-pet-X.Y.Z-windows-x64.zip` 和 `SHA256SUMS.txt`；校验大小及 SHA-256（存在 GitHub digest 时也需一致）。HTTPS 和仓库发布权限是信任基础，目前没有代码签名或独立签名更新清单。更新说明按纯文本显示，不执行其中的链接或 HTML。

更新在安装目录旁完整准备，检查文件路径、文件数量、大小、重复/链接及程序结构，再由独立 Windows PowerShell 助手重新核对所有暂存文件摘要。助手确认就绪后桌宠才退出。助手等待旧进程退出，交换目录并启动新版；新版未写入对应版本运行状态时回退旧目录并重启。旧安装保留为相邻 `.previous-*` 备份，确认新版正常后可自行移除备份。下载缓存及未完成暂存也可在应用退出后清理，清理前确认不是当前安装目录。

用户数据仍在 `%LOCALAPPDATA%/WorkBuddyDesktopPet`，包含设置、角色库、事件和授权开关；更新不覆盖这些文件，不重新授予权限，不更改自启选择。快捷方式目标不变。若自定义 `--root` 放在程序目录内部，自动安装会拒绝，需手动更新并保留数据；建议把数据放在独立目录。

安装目录或其父目录不可写时，不申请提升权限覆盖系统目录；界面提示失败，可在本仓库 Releases 手动下载解压。源码运行只检查版本，程序替换使用 Git。**0.5.1 及更早版本没有更新器，首次需手动安装当前正式版，此后的正式版本才可使用内置更新。**

发布者必须上传程序 ZIP、校验文件及安装说明后再发布正式版本并设为 latest；v0.6.4的唯一默认套装已内置，不另发布旧模板或独立默认包；公开前先验证 Windows CI、冻结包、目录交换/回退及匿名下载。不要覆写已发布附件。
